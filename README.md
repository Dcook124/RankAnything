This is a project based on the card game 
Players choose 8 things. They can be characters, foods, stories, literally anything 
They then choose a random category to rank them by e.g. "Who would make the best therapist?", "Who would be the best football coach" etc 
Players then rank the 8 items from S-A-B-C-D-E where S rank is the highest and E rank is the lowest
This is working between machines
